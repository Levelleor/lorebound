# Story Mode First Complete Turn

## Context

Approved design decision. This does not certify delivery. Later accepted constraints override only the clauses they address.

## Explicit user approval

User selected **C-D04 A, C-D05 C, C-D06 A** and required recording only accepted choices, preservation of staging/architecture history, no implementation or promotion, and continuation in batches of three.

**ACCEPTED: A.** The first story-loop slice uses Story mode and a single freeform submitted action/passage to drive provisional narrative processing, accepted story history and deterministic reconstruction. Do/Say/Continue remain accepted product requirements but are outside this first narrow slice. Do not require character selection or full gameplay simulation in the first scope. The provisional result is not canonical until the ordinary accepted atomic transaction. This is scope refinement, not an additional approval stage.

## Alternatives and chronological authority

B would demand all four action modes in the initial slice; C would give only a read-only display and no accepted turn. Neither was chosen.
