# Zoomable Node Map Canvas

## Idea
Display the world as a pannable, zoomable non-overlapping graph canvas with nested groups.

## Why consider it?
Makes discovered places and buildings easy to navigate.

## Rough behaviour
Show region/town/building/room nodes, connections and selection details; allow user-driven layout and collision avoidance.

## Variations and alternatives
React Flow is one candidate, not an accepted framework.

## Open questions and risks
- At what zoom levels should children collapse, and how are layout positions saved?

- Origin: **user**. User-requested direction; exact mechanics remain to be reviewed.
