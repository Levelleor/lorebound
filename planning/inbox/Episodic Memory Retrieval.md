# Episodic Memory Retrieval

## Idea
Retrieve detailed old incidents when they become relevant again.

## Why consider it?
Summaries can omit small but important earlier events.

## Rough behaviour
Index memories by entities, turns and optionally embeddings; select by relevance.

## Variations and alternatives
Keyword/event lookup first versus vector embeddings.

## Open questions and risks
- Can retrieval work well without loading another model?
