# Bundled typefaces

These unmodified fonts are served locally so the Command Citadel typography works offline without sending browser requests to a font service.

Source: [Google Fonts at cc39c4c2c304bc368c9b7c311ea2bcc6013299fe](https://github.com/google/fonts/tree/cc39c4c2c304bc368c9b7c311ea2bcc6013299fe).

| IBMPlexSans.ttf, IBMPlexSans-Italic.ttf | [IBM Plex Sans](https://github.com/google/fonts/tree/cc39c4c2c304bc368c9b7c311ea2bcc6013299fe/ofl/ibmplexsans); upstream filenames end in `[wdth,wght].ttf` | [OFL-Plex.txt](./OFL-Plex.txt) |
| IBMPlexMono-Regular.ttf, IBMPlexMono-Medium.ttf | [IBM Plex Mono](https://github.com/google/fonts/tree/cc39c4c2c304bc368c9b7c311ea2bcc6013299fe/ofl/ibmplexmono) | [OFL-Plex.txt](./OFL-Plex.txt) |
